# 로얄마린 수영장 통합관리

- `docs/index.html` — 관리자 웹 (원장·강사)
- `docs/parent.html` — 학부모 웹앱 (휴대폰 홈 화면에 추가)
- `supabase/` — 데이터베이스와 보안 규칙(RLS)
  - `01_schema.sql` 테이블·보안 규칙·함수 (처음 한 번)
  - `02_fake_data.sql` 테스트용 가짜 데이터
  - `03_clear_fake_data.sql` 실제 데이터 넣기 전에 가짜 데이터 삭제
  - `04_make_me_admin.sql` 원장님 계정을 관리자로 지정

## 보안 요약
- 모든 테이블에 RLS. 로그인하지 않은 사람은 아무것도 읽을 수 없음.
- 관리자: 전체 / 강사: 담당 반의 명단·출석·진도만 / 학부모: 연결된 자기 아이의 공개 항목만(함수로만 조회).
- 주소·내부 메모는 `member_private` 테이블에 분리 — 관리자만.
- 초대코드는 8자리·1회용·30일 만료, 틀린 입력 1시간 5회 제한.
- 엑셀은 브라우저 안에서만 읽고 파일은 업로드하지 않음.
- `docs/config.js`에는 공개용(anon/publishable) 키만. service_role 키는 절대 넣지 않음.
